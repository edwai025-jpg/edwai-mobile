o	fontSize, lineHeight, fontFamily (system / serif / sans) — user preference from Settings

•	Uses ReactMarkdown + remarkGfm + remarkMath + rehypeKatex
•	Pre-processes: \[...\] → $$...$$, \(...\) → $...$

•	Tables: overflow-x-auto, border-collapse border border-gray-300
•	Code blocks: bg-gray-100 p-3 rounded font-mono
•	Blockquote: border-l-4 border-blue-400 pl-3 italic

Condition	Color	Icon

confidence >= 0.6	yellow-50 / yellow-200	⚠️
confidence < 0.6	red-50 / red-200	❌

17. Query Response Shapes
Phase 1 — POST /api/query
{
  "answer": "string (markdown)",
  "sources": [
    {
      "page": 42,
      "base64_images": [
        {
          "page": 42,
          "data": "data:image/jpeg;base64,...",
          "ncert_url": "https://ncert.nic.in/..." // only in embedded mode
        }
      ]
    }
  ],
  "diagram_images": [
    { "page": 12, "data": "data:image/jpeg;base64,..." }
  ],
  "validation": {
    "is_reliable": true,
    "confidence": 0.93,
    "validated_facts": 5,
    "partial_facts": 0,
    "unverified_facts": 1,
    "warnings": ["..."]
  },
  "cached": false
}
Phase 2 — POST /api/phase2/query
{
  "answer": "string (markdown)",
  "citation_images": [
    {
      "page_number": 7,
      "base64_image": "..."  // raw base64, no prefix
    }
  ]
}
Streaming format: SSE events, each data: {"chunk": "..."}. Final event: data: [DONE].
