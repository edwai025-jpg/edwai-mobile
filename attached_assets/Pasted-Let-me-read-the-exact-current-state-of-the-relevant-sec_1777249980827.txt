_ALLOWED_MOBILE_SCHEMES = ("edwai://",)
def _is_safe_mobile_redirect(url):

What the mobile app gets back

After Google sign-in, the in-app browser is redirected to:

edwai://auth/google/callback
  ?token=<JWT_access_token>
  &refresh_token=<refresh_token>
  &profile_complete=true|false

Your mobile app should:

    Parse token → store in memory, send as Authorization: Bearer {token} on every request
    Parse refresh_token → store in Keychain/Keystore, use it to call POST /api/auth/token/refresh when you get a 401
    Check profile_complete → false means navigate to Complete Profile screen, true means go to Home
