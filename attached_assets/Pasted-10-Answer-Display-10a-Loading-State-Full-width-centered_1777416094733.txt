10c. Final Answer Card
Same card style as streaming. Layout:

✨ icon 40×40
"Answer" text-lg font-bold
<AnswerRenderer> with typography settings:
fontSize, lineHeight, fontFamily (system / serif / sans) — user preference from Settings
AnswerRenderer component behavior:
Uses ReactMarkdown + remarkGfm + remarkMath + rehypeKatex
Pre-processes: \[...\] → $$...$$, \(...\) → $...$
Page citations: [Page N] → **[Page N]** (bolded)
Tables: overflow-x-auto, border-collapse border border-gray-300
Code blocks: bg-gray-100 p-3 rounded font-mono
Blockquote: border-l-4 border-blue-400 pl-3 italic
Validation Badge (Explain mode only)
If answer.validation present:

Condition	Color	Icon
is_reliable = true	green-50 / green-200	✅
confidence >= 0.6	yellow-50 / yellow-200	⚠️
confidence < 0.6	red-50 / red-200	❌
Shows: "Answer Validation: N% Verified", count of verified/partial/unverified statements, any warnings.

Teacher Save Button (teachers only, Phase 1, uncached answers)
💾 Save This Answer → amber button. Success: ✓ Answer Saved (green). Duplicate: shows similarity %.

API: POST /api/teacher/save-answer

12. Flashcard Section
Appears below the answer (when answer.answer exists and not streaming). Component: <FlashcardSection question={question} answer={answer.answer} isPrimary={isPrimary} />.

Trigger API: POST /api/generate-flashcards

{ "question": "...", "answer": "..." }

Response: { flashcards: [{ type, front, back }] }

Card types & colors:

Type	Gradient (front face)
definition	violet-600 → indigo-700
concept	sky-500 → blue-600
process	emerald-500 → teal-600
fact	amber-500 → red-500
diagram	pink-500 → purple-600
All cards: text-white font-bold, min-height 220px.

3D flip animation: rotateY(180deg) on tap; transform-style: preserve-3d; perspective: 1000px.

Front face shows front + type label (e.g. "DEFINITION"). Back face shows back.

Navigation: previous/next arrows. Pagination dots.
