Layout (web: two-column; mobile: single column)

    Left panel (desktop only): Marketing copy, feature highlight cards, stock photo

    +91 prefix box (gray, non-editable) + input field for 10-digit number

    Single email input field with inline validation (real-time on blur)

18. Key UX Patterns for Mobile Replication

    Skeleton/pulse loading — use on all async data loads before content appears
    Toast notifications — green success / red error pop from top or bottom, auto-dismiss ~3s
    Streaming responses — text chunks arrive via SSE; render progressively in the answer card
    Optimistic UI — answer card appears immediately with spinner, then fills
