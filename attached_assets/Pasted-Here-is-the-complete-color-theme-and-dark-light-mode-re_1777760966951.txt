Here is the complete color theme and dark/light mode reference for the mobile project:
EdwAI Color Theme & Dark/Light Mode — Mobile Reference Spec
1. Theme System

Storage key: theme-storage (Zustand persist → localStorage)
Field: mode
Values: "primary" (dark/deep blue) | "secondary" (light/cream)
Default: "primary"

On mobile, persist this in AsyncStorage under the same key "theme-storage" and hydrate it on app start.
2. Brand Colors (Tailwind config)
Token	Hex	Use
primary	#667eea	Accent, CTA buttons, scrollbar thumb, active states
primary-dark	#5568d3	Hover state of primary buttons
secondary	#faf8f3	Light mode background surface
secondary-dark	#e8e5df	Light mode card hover / pressed state
3. Page-level Background
Mode	Value
Dark (primary)	linear-gradient(135deg, #1a1a2e → #16213e) (bottom-right)
Light (secondary)	linear-gradient(135deg, blue-50 → white → purple-50)

In React Native use: dark ['#1a1a2e', '#16213e'], light ['#eff6ff', '#ffffff', '#faf5ff'] with LinearGradient at { start: {x:0,y:0}, end: {x:1,y:1} }.

5. Banner / Navigation Bar

The banner is always dark-purple regardless of light/dark mode — it does not flip. It is a sticky full-width strip.

Light mode:  linear-gradient(135deg, #3730a3 0%, #4f46e5 40%, #6d28d9 75%, #4338ca 100%)

Drop shadow on both: rgba(99,71,234,0.35) blur 32px.
