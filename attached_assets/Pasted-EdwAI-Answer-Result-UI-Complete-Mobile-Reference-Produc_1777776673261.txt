EdwAI — Answer Result UI: Complete Mobile Reference

Production Base URL:

https://edwai-api-953672603784.asia-south1.run.app

Part 1 — Setup Calls (Once Per Session)

Make these three calls immediately after login, before the user asks any question. Cache the results for the session.
1a. Typography Settings

GET /api/typography-settings
Authorization: Bearer <token>

Response:

{
  "font_size": "16px",
  "line_height": "1.7",
  "font_family": "system"
}

Valid values: font_size → "14px" | "16px" | "18px" | "20px" · line_height → "1.5" | "1.7" | "1.9" · font_family → "system" | "serif" | "sans-serif"

Apply these to the answer text block. Default if the call fails: 16px / 1.7 / system.
1b. Disclaimer Messages

GET /api/disclaimer-messages
Authorization: Bearer <token>

Response:

{
  "ai_warning_text": "⚠️ AI may produce wrong/under/over responses...",
  "page_context_text": "Please check the adjacent pages for full context...",
  "source_citation_text": "EdwAI Generated Content using related syllabus/context..."
}

All three are strings. Any can be empty — only render them if non-empty.
1c. Board Page Config (fetch when user's board_id is known)

GET /api/boards/{board_id}/page-config
Authorization: Bearer <token>

Response:

{
  "board_id": 4,
  "page_display_mode": "original",
  "ncert_book_code": null
}

page_display_mode is one of: "original" · "edwai_generated" · "embedded"

Store this as boardPageConfig. Default if call fails: { page_display_mode: "original", ncert_book_code: null }.
Part 2 — Answer Response Shape

The query endpoints (POST /api/query and POST /api/query/stream) return:

{
  "answer": "Photosynthesis is the process...",
  "sources": [
    {
      "page": 34,
      "base64_images": []
    }
  ],
  "diagram_images": [],
  "citation_images": [],
  "cached": false,
  "validation": {
    "is_reliable": true,
    "confidence": 0.87,
    "validated_facts": 5,
    "partial_facts": 1,
    "unverified_facts": 0,
    "warnings": []
  },
  "image_source_pages": [34, 35],
  "document_id": 12,
  "is_visual_question": false
}

Key fields:

    answer — markdown + LaTeX text, always present
    sources — array of { page: int } objects — page numbers for the source badge pills
    image_source_pages — array of page numbers to fetch images for (POST to /api/query/images asynchronously after answer arrives)
    validation — optional, only present for "explain" mode
    cached — if true, this answer came from cache (not from live LLM call)
    Phase 2 answers have citation_images directly in the response (no separate fetch needed)

Part 3 — Separate Image Fetch (Phase 1 Only, After Answer)

After the answer arrives (or the stream done event fires), if image_source_pages is non-empty and it is not a Phase 2 document, fire this call:

POST /api/query/images
Authorization: Bearer <token>
Content-Type: application/json
{
  "document_id": 12,
  "pages": [34, 35],
  "include_diagrams": false
}

Set include_diagrams: true only when answer.is_visual_question === true.

Response:

{
  "diagram_images": [
    { "filename": "page_34_img0.png", "data": "data:image/png;base64,...", "page": 34 }
  ],
  "citation_images": [
    { "filename": "page_034.png", "data": "data:image/png;base64,...", "page": 34, "pdf_page": 34 }
  ],
  "page_display_mode": "original"
}

For embedded mode, citation items look like:

{ "page": 34, "ncert_url": "https://ncert.nic.in/textbook.php?...", "data": null }

Merge this into the answer state: put citation_images into answer.sources[0].base64_images and diagram_images into answer.diagram_images.

BOX 4 — Page Citations

Show only when answer.sources?.[0]?.base64_images?.length > 0 (Phase 1) OR answer.citation_images?.length > 0 (Phase 2).
4a. Phase 2 Citations (Own books / YouTube)

Always shows image cards. Data comes directly in the query response (no separate fetch needed).

Field: answer.citation_images[n].base64_image — raw base64 string (no prefix)
Page number field: citation.page_number

image src = `data:image/jpeg;base64,${citation.base64_image}`

Render as full-width image card with "Page {page_number}" label below. Tap to zoom.
4b. Phase 1 Citations — Three Display Modes

The citation box header is always:

    Icon: 📖, title: "Page Citations"
    Page context notice (if disclaimerMessages.page_context_text non-empty) — blue info box above citations

Decide which branch to render:

if (boardPageConfig.page_display_mode === 'embedded'
    AND citation_images.some(c => c.ncert_url))
    → render EMBEDDED mode
else
    → render IMAGE mode (original or edwai_generated look identical to the user)

EMBEDDED Mode (NCERT Books)

No images shown. Render a green card with link buttons per page.

IMAGE Mode (Original or EdwAI Generated)

Render each citation as a full-width image card. Max 5 pages shown (pages[:5] server-enforced).
Element	Value

Card bg	#ffffff
Image	full width, citation.data (already a data URL with prefix)

For edwai_generated mode — the server tries AI-generated images from phase1/ai_images/doc_{id}/page_{NNN}.png and falls back to original scans. The data URL format is identical — no difference in how the mobile renders them. The frontend also tries GET /api/ai-images/{doc_id}/page_{NNN:03d}.png per page directly (with auth header), then falls back to the batch /api/query/images endpoint. On mobile, just use the batch endpoint — it handles the mode internally.

BOX 6 — Flashcard Practice

Show only after answer is fully received and streaming is false. See full flashcard spec (previously provided). Condition: answer.answer && !streaming.
Part 5 — Streaming State

While the answer is streaming in (SSE), show only Box 2 with the "typing…" indicator. Boxes 3–6 do not appear until streaming is complete. The image fetch (POST /api/query/images) is triggered by the done SSE event — add a 300ms delay before firing it.

SSE done event payload:

{
  "type": "done",
  "answer": "full answer text",
  "sources": [...],
  "image_source_pages": [34, 35],
  "document_id": 12,
  "is_visual_question": false,
  "cached": false,
  "validation": {...}
}

Part 6 — Loading States
State	What to show
Initial query loading (before first SSE token)	Spinner + "Searching through your textbook..."
Streaming in progress	Box 2 with answer text + "typing..." pulse
Images loading (after stream done)	Small inline spinner row: "Loading source images..."
Images arrived	Replace spinner with Box 4/5
Part 7 — Full-Screen Zoom Modal

When any citation image or diagram image is tapped, open a full-screen modal overlay:
Element	Value
Backdrop	rgba(0,0,0,0.85)
Image	fit to screen, pinch-to-zoom supported
Caption	"Page {n}" white text at bottom
Close	tap outside or × button

The modal receives: { data: dataUrl, page: number, type: 'citation' | 'diagram' }.
